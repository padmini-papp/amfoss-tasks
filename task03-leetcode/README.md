# Leetcode Challenge

Task 03 for amFOSS. Solved 5 problems on leetcode, 3 easy and 2 medium (plus one extra easy one).

## Problems solved

1. Two Sum (Easy)
2. Valid Parentheses (Easy)
3. Palindrome Number (Easy)
4. Container With Most Water (Medium)
5. Maximum Subarray (Medium)
6. Maximum Depth of Binary Tree (Easy, extra)

Each .cpp file in this folder has the code along with a short explanation of the approach used, written as a comment at the bottom of each file.

## Concepts learned

- Hash maps for O(n) lookups instead of nested loops (Two Sum)
- Using a stack to check for matching/balanced pairs (Valid Parentheses)
- Two pointer technique for array problems (Container With Most Water)
- Kadane's algorithm for maximum subarray sum problems
- Recursive tree traversal (Maximum Depth of Binary Tree)
- Avoiding integer overflow by using long instead of int where needed (Palindrome Number)
