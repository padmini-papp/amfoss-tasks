## Task 00 - Install Linux

I'm using a MacBook Air, and since the task says it's fine to do everything on either Linux or macOS, I didn't need to install Linux separately.

For package management on Mac I used Homebrew, which is basically the same idea as apt or pacman on Linux, just for Mac. I installed it through the terminal and used it throughout the rest of the tasks to install things like Python packages, Git, etc.
